# خط عربي لتقارير PDF

ضع هنا ملف خط عربي حقيقي باسم `arabic.ttf` لتفعيل عرض النصوص العربية بشكل
صحيح داخل تقارير PDF (لوحة الإدارة ← تصدير تقرير الغياب).

خطوط مجانية مقترحة (رخصة مفتوحة، تدعم العربية بالكامل):
- Amiri: https://github.com/aliftype/amiri
- Noto Naskh Arabic: https://fonts.google.com/noto/specimen/Noto+Naskh+Arabic

نزّل ملف `.ttf` وضعه هنا بالاسم `arabic.ttf`، أو حدّد مسارًا مختلفًا عبر
متغير البيئة `ARABIC_FONT_PATH` في ملف `.env`.

بما أن شبكة المدرسة محلية غالبًا بدون إنترنت (حسب وثيقة المعمارية)، يُفضَّل
تنزيل الخط مرة واحدة على حاسوب لديه اتصال ثم نسخه إلى الخادم عبر USB مع بقية
إعداد النشر، بدل الاعتماد على تنزيله وقت التشغيل.

إن لم يوجد الملف، سيعمل التقرير بخط Helvetica الافتراضي مع تنبيه واضح في
أعلى الملف الناتج (النص العربي لن يظهر بشكل صحيح في هذه الحالة).
