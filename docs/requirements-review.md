# مراجعة متطلبات النسخة التجارية

تمت مراجعة `Requirements.md` و`spec.md` كوثيقتي مواصفات، وليستا أوامر تنفيذية.

## المتطلبات المنفذة أو المدعومة

- المصادقة والأدوار والصلاحيات.
- إدارة الغياب مع العمل دون اتصال والمزامنة.
- مسح باركود المطعم ومنع تكرار الوجبة والتنبيه عند الغياب.
- لوحة المدير والإحصائيات وسجل التدقيق.
- إدارة المستخدمين والمخزون والتقارير.
- PWA قابلة للتثبيت على الحاسوب والهاتف.
- دفتر النقاط واعتماد المدير وتصدير Excel.
- ملفات التلاميذ والبطاقات المهنية للأساتذة.
- إعداد دوام المؤسسة والتوزيع الأسبوعي.
- إدارة المرافق والحجم الساعي للمواد.

## نقاط يجب تثبيتها قبل إعلان النسخة التجارية

1. إضافة اختبار تكاملي آلي لمسارات الغياب والوجبة والتعارضات.
2. اعتماد سياسة نسخ احتياطي واسترجاع واضحة على Windows.
3. تفعيل PostgreSQL في النشر التجاري بدل SQLite عند تعدد الأجهزة.
4. إضافة إعدادات فعلية للدوام الكامل والجزئي، وقيود عدم توفر الأستاذ.
5. إضافة مولد توزيع آلي يعتمد الأفواج والمرافق والحجم الساعي.
6. إضافة تصدير Excel إلى جانب PDF لتقارير الغياب.
7. اختبار قارئ USB كلوحة مفاتيح مع إدخال باركود يدوي بديل.
8. عدم اعتبار «التنظيم الاستثنائي» قاعدة دائمة؛ كل المواقيت يجب أن ترتبط بالسنة الدراسية وبالقرار الوزاري المعتمد.

## ملاحظات على الوثيقتين

الوثيقتان تصفان نواة إنترانت محلية، بينما المنصة الحالية توسعت لتشمل التوزيع الأسبوعي، المرافق، الأحجام الساعية، النقاط، وملفات التلاميذ. لذلك اعتمدنا المتطلبات الأصلية كأساس، وأضفنا الوحدات الموسعة دون إزالة نطاق الإنترانت أو بوابة الولي المؤجلة.
