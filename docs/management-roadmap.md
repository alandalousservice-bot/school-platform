# مقترح تنظيم إدارة المؤسسة والميزانية

هذه الوثيقة تقترح طريقة تشغيل عملية للمنصة، حتى لا تتحول لوحة الإدارة إلى مجموعة شاشات منفصلة.

## 1. الهيكل الإداري المقترح

| الوحدة | مسؤولها | القرار الذي تدعمه |
|---|---|---|
| لوحة المتابعة | المدير | ما الذي يحتاج تدخلًا اليوم؟ |
| التلاميذ والملفات | المدير / المكلف بالدراسة | هل السجل موحد ومحدث؟ |
| الغياب والنقاط | الأستاذ ثم المدير | ما الذي سُجل؟ وما الذي يحتاج اعتمادًا؟ |
| التوزيع والمرافق | المدير | هل الموارد والجدول متوازنان؟ |
| الميزانية والاعتمادات | المدير | كم رُصد؟ كم صُرف؟ وما المتبقي؟ |
| المطعم والمخزون | مشرف المطعم | ما الذي يجب تموينه الآن؟ |
| حسابات الطاقم | المدير | من يملك صلاحية كل عملية؟ |

كل وحدة لها شاشة مستقلة، لكن السجل التدقيقي يربط العمليات بالمستخدم والتاريخ.

## 2. طريقة ترتيب الميزانية

يُنصح بتقسيم الاعتماد السنوي إلى محاور ثابتة:

1. **التسيير اليومي:** لوازم مكتبية، مطبوعات، مواد النظافة.
2. **المطعم المدرسي:** المواد الغذائية والتموين.
3. **التجهيزات:** أثاث، أجهزة، وسائل تعليمية.
4. **الصيانة والإصلاح:** الكهرباء، السباكة، الطلاء، الشبكة.
5. **الأنشطة التربوية:** الأنشطة الثقافية والرياضية والنوادي.
6. **الطوارئ:** احتياطي لا يُستهلك إلا بسبب موثق.

لكل بند يجب تسجيل:

- اسم واضح ومحدد.
- السنة الدراسية.
- المبلغ المرصود.
- النفقة الفعلية مع وصفها أو رقم الفاتورة.
- المتبقي تلقائيًا.
- ملاحظة مصدر التمويل أو سبب الاعتماد.

تمنع المنصة تسجيل نفقة تتجاوز الاعتماد المتبقي، وتحتفظ بسجل حركة يمكن مراجعته بدل تعديل الأرقام يدويًا.

## 3. دورة اعتماد عملية

```text
تقدير الاحتياج
  → إنشاء بند اعتماد
  → مراجعة المدير
  → تسجيل النفقة والفاتورة
  → متابعة المتبقي
  → إغلاق البند نهاية السنة
```

يفضل إجراء مراجعة شهرية قصيرة في أول أسبوع من كل شهر:

- مراجعة نسبة التنفيذ لكل محور.
- تحديد البنود التي استُهلك أكثر من 80% منها.
- مقارنة المخزون مع اعتماد المطعم.
- تسجيل الالتزامات المتوقعة قبل نهاية الفترة.

## 4. الصلاحيات والضبط

- **المدير:** إنشاء الاعتمادات، تسجيل النفقات، الإغلاق، والتقارير.
- **مشرف المطعم:** إدارة المخزون والاستهلاك، دون تعديل اعتماد الميزانية.
- **الأستاذ:** لا يرى البيانات المالية؛ يركز على الغياب والنقاط.
- **المدير العام:** مراجعة شاملة عند الحاجة.

لا يُنصح بالحذف النهائي للحركات المالية. عند الخطأ، يسجل تصحيح جديد بوصف واضح ويبقى الأصل في سجل التدقيق.

## 5. اقتراحات المرحلة التالية

1. إضافة رفع نسخة الفاتورة وربطها بحركة الصرف.
2. إضافة تصدير تقرير مالي PDF وExcel حسب السنة والمحور.
3. إضافة تنبيه تلقائي عند وصول التنفيذ إلى 80% أو قرب نفاد المخزون.
4. إضافة إقفال شهري يمنع تعديل الفترات المراجعة إلا بصلاحية المدير العام.
5. إضافة نسخ احتياطي يومي مع اختبار استرجاع شهري، وليس مجرد إنشاء ملف النسخة.
6. إضافة لوحة مؤشرات للالتزامات المتوقعة، وليس للمصروف الفعلي فقط.
7. اعتماد PostgreSQL عند تشغيل عدة أجهزة بالتوازي، مع الإبقاء على SQLite للتجربة المحلية.

## 6. مبدأ التصميم

لا تعرض المنصة أرقامًا كثيرة بلا قرار. كل بطاقة أو رسم يجب أن يقود إلى إجراء: اعتماد، تسجيل نفقة، إعادة تموين، مراجعة غياب، أو استخراج تقرير.
